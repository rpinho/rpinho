# Ricardo Pinho

Data engineer with a PhD in computational biology. I use AI agents, mostly Claude Code and Codex, on open science problems and publish the code and the results. Results are unrefereed unless a paper says otherwise.

## Biology

- [virtual-cell-challenge](https://github.com/rpinho/virtual-cell-challenge): pipeline and local evaluation harness for the Arc Virtual Cell Challenge 2026.
- [Virtual Embryo Challenge](https://virtualembryo.ai): competing now. No public repo yet.
- [adaptyv-challenges](https://github.com/rpinho/adaptyv-challenges): entries to the Adaptyv/Anthropic protein design competition, challenges 3 to 5.
- [louis](https://github.com/rpinho/louis): pick an autoimmune disease and get trust-ranked CD4+ T-cell drug targets from a genome-scale Perturb-seq screen.
- [autoregulation](https://github.com/rpinho/autoregulation): gene regulatory network stability analysis, code from my PhD (Feldman lab, Stanford).

## Math

- [math-certificates](https://github.com/rpinho/math-certificates): index of explicit, independently checked bounds on open optimization constants. Each certificate has its own repo and checkers.

## Astronomy

- [planet-hunt](https://github.com/rpinho/planet-hunt): AI agents searching NASA TESS data for small planets. Four candidate-planet research notes submitted to the AAS.

## Learning

- [family-learning-games](https://github.com/rpinho/family-learning-games): ten self-hosted learning games and an illustrated story book in one hub.

## Agents and tools

- [agent-kb](https://github.com/rpinho/agent-kb): a file-based knowledge base that agents maintain, with its rules enforced by mechanisms instead of prose.
- [sentinel](https://github.com/rpinho/sentinel): two-stage incident detector for open-source repos, built with Codex.
- [prediction-market-mm](https://github.com/rpinho/prediction-market-mm): a passive market maker for the Orderbook Prediction Market Challenge, plus the harness used to tune it.
